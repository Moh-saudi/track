# منظومة تتبع القضايا — اللجنة العليا للمسئولية الطبية

هيكل برمجي أولي (Scaffold) مبني على أساس مستند متطلبات المنتج (PRD)، جاهز للتشغيل محليًا
وقابل للترحيل لاحقًا لسيرفرات وزارة الصحة والسكان.

## الحزمة التقنية

- **الواجهة الأمامية والخلفية:** Next.js 14 (App Router) + TypeScript
- **قاعدة البيانات:** PostgreSQL عبر Prisma ORM
- **المصادقة:** NextAuth (Credentials Provider) + bcrypt، بدون أي اعتماد على Supabase أو مزود خارجي
- **الصلاحيات (RBAC):** مصفوفة أدوار مطابقة لقسم ٨ في الـ PRD، مطبّقة في `src/lib/rbac.ts` و `src/middleware.ts`
- **الملفات المرفقة:** تخزين محلي على القرص (`/uploads`) في هذه المرحلة، قابل للاستبدال لاحقًا بخدمة تخزين على سيرفر الوزارة
- **التدقيق:** سجل Audit Log تلقائي لكل عملية إنشاء/تعديل رئيسية (`src/lib/audit.ts`)

## المتطلبات الأساسية

- Node.js 20 أو أحدث
- Docker (لتشغيل PostgreSQL محليًا) — أو أي سيرفر PostgreSQL محلي بديل

## خطوات التشغيل المحلي

```bash
# 1) تثبيت الحزم
npm install

# 2) تشغيل قاعدة بيانات PostgreSQL محليًا عبر Docker
npm run db:up

# 3) نسخ ملف متغيرات البيئة وتعديله
cp .env.example .env
# افتح .env وولّد قيمًا عشوائية لكل من:
#   NEXTAUTH_SECRET       -> openssl rand -base64 32
#   FIELD_ENCRYPTION_KEY  -> openssl rand -hex 32

# 4) إنشاء جداول قاعدة البيانات
npx prisma migrate dev --name init

# 5) تعبئة البيانات الأولية (اللجان الفرعية الـ16 + مستخدم مدير)
npm run prisma:seed

# 6) تشغيل السيرفر المحلي
npm run dev
```

بعد ذلك افتح `http://localhost:3000` وسجّل الدخول بالحساب الافتراضي:

- **البريد الإلكتروني:** `admin@example.local`
- **كلمة المرور:** `ChangeMe123!` — غيّرها فورًا (لا توجد حاليًا شاشة لتغيير كلمة المرور، عدّلها عبر `npx prisma studio` مؤقتًا)

## حالة الإنجاز الحالية (Scaffold أولي)

تم بناء:
- نموذج بيانات كامل مطابق لكل كيانات الـ PRD، بما فيها نوع التسجيل (شكوى/قضية/محضر)، توصيف الخطأ، تاريخ انعقاد اللجنة العليا، والمرفقات
- تسجيل الدخول والصلاحيات والحماية على مستوى المسارات
- تدفق العمل الكامل: تسجيل → توجيه → دراسة فرعية → قرار اللجنة العليا → تسوية مالية
- رفع وعرض المرفقات لكل قضية

لم يُبنَ بعد (خطوات تالية مقترحة):
- إنشاء سجلات الجدول المالي تلقائيًا عند اعتماد قرار اللجنة العليا (حاليًا الجدول يُدار يدويًا)
- واجهات إدارية كاملة لإضافة/تعديل اللجان الفرعية وأعضائها والمستخدمين (بديل لـ Prisma Studio)
- شاشة تغيير كلمة المرور وإعادة تعيينها
- اختبارات آلية (Unit / Integration tests)
- تجهيزات الإنتاج (Rate limiting فعلي، فحص فيروسات للملفات المرفوعة، نسخ احتياطي مجدول)

## الترحيل لسيرفرات وزارة الصحة والسكان

المشروع لا يعتمد على أي خدمة سحابية خارجية (لا Supabase ولا أي مزود مصادقة/تخزين خارجي)، لذا
تقتصر خطوات الترحيل مستقبلًا على:
1. نسخ قاعدة بيانات PostgreSQL (`pg_dump` / `pg_restore`) إلى سيرفر الوزارة
2. نقل مجلد `/uploads` (أو ربطه بخدمة تخزين ملفات داخلية للوزارة)
3. ضبط متغيرات البيئة على السيرفر الجديد وتشغيل `npm run build && npm run start`
