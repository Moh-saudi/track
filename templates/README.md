# دليل ونموذج الحصر والرفع الجماعي لأطباء واستشاريي اللجان الفرعية
**جمهورية مصر العربية — رئاسة مجلس الوزراء**  
**اللجنة العليا للمسؤولية الطبية وسلامة المريض**

---

## 🎯 الهدف من النموذج
إتاحة نموذج إكسيل موحد وسهل لجمع بيانات أطباء واستشاريي اللجان الفرعية الـ 16 المعتمدة دفعة واحدة، ليقوم المبرمج / مدير المنظومة برفعها مباشرة إلى قاعدة البيانات بتشفير حكومي كامل (AES-256-GCM)، مما يختصر وقت الإدخال اليدوي الفردي ويترك لمقرري وموظفي اللجان مستقبلاً مهمة إضافة الأطباء الجدد فقط.

---

## 📁 الملفات المتوفرة في هذا المجلد:
1. `doctors_import_template.xls`:
   - ملف إكسيل احترافي ملوّن متعدد أوراق العمل (Workbook) يدعم اتجاه اليمين إلى اليسار (RTL).
   - يتضمن أوراق العمل التالية:
     - **ورقة 1 (بيانات أطباء اللجان الفرعية):** الجدول المخصص لتعبئة البيانات مع 5 نماذج استرشادية واقعية.
     - **ورقة 2 (دليل اللجان الفرعية المعتمدة):** قائمة باللجان والجهات الـ 16 وأكوادها الرسمية.
     - **ورقة 3 (دليل التخصصات المعيارية):** قائمة بكافة التخصصات الطبية المعيارية الـ 34 المعتمدة بالمنظومة.
     - **ورقة 4 (تعليمات وإرشادات التعبئة):** ضوابط تعبئة كل حقل بدقة.
2. `doctors_import_template.csv`:
   - ملف بصيغة CSV مشفرة بترميز `UTF-8 with BOM` يفتح مباشرة باللغة العربية في كافة برامج الإكسيل دون أي تشويه للأحرف.

## 📋 أعمدة النموذج والبيانات المطلوبة:
| # | العمود | الأهمية | إرشادات التعبئة |
|---|---|---|---|
| 1 | **اسم اللجنة الفرعية (أو كودها)** | إلزامي | كتابة اسم اللجنة المعتمدة (مثل: `كلية طب جامعة القاهرة (قصر العيني)`) أو كودها (مثل: `SC-03`). |
| 2 | **اسم الطبيب الاستشاري** | إلزامي | الاسم ثلاثياً أو رباعياً بدون ألقاب (مثل: `أحمد محمود حسن إبراهيم`). |
| 3 | **اللقب العلمي** | اختياري | مثل: `أستاذ دكتور` / `أستاذ مساعد` / `استشاري` / `زميل`. |
| 4 | **التخصص الطبي** | إلزامي | التخصص الطبي المعياري (مثل: `جراحة عامة`، `التخدير وعلاج الألم`، إلخ). |
| 5 | **جهة العمل / المستشفى الأصلية** | إلزامي | المستشفى أو الكلية التابع لها (أساسي لمنع وفحص تعارض المصالح آلياً). |
| 6 | **الرقم القومي** | إلزامي | 14 رقماً مصرياً لصرف المكافآت والبدلات المالية (يُشفر تلقائياً في النظام). |
| 7 | **رقم الهاتف المحمول** | إلزامي | 11 رقماً يبدأ بـ `01` للتواصل وإرسال الإخطارات والتكليفات. |
| 8 | **طريقة الصرف المالي** | إلزامي | `فيزا مرتبات` / `حساب بنكي` / `كارت ميزة`. |
| 9 | **اسم البنك** | عند الحساب البنكي | مثل: `البنك الأهلي المصري`، `بنك مصر`، `CIB`، `بنك القاهرة`. |
| 10 | **رقم كارت الفيزا / ميزة** | عند اختيار كارت | 16 رقماً للكارت البنكي لصرف المستحقات. |
| 11 | **رقم الحساب البنكي** | عند الحساب البنكي | رقم الحساب البنكي الخاص بالطبيب. |
| 12 | **رقم الآيبان (IBAN)** | اختياري | رقم الآيبان الدولي إن وجد (يبدأ بـ `EG`). |
| 13 | **ملاحظات إدارية** | اختياري | أي خبرات خاصة أو مهام إدارية سابقة (مثل: رئيس قسم أسبق). |

## 🚀 أوامر الرفع للمبرمج (Admin Commands)

### 1. فحص وتدقيق الملف فقط دون حفظ (Dry Run):
```bash
npm run doctors:import -- templates/doctors_import_template.xls --dry-run
# أو لملف CSV:
npm run doctors:import -- templates/doctors_import_template.csv --dry-run
```

### 2. التنفيذ الفعلي والرفع المباشر لقاعدة البيانات:
```bash
npm run doctors:import -- templates/doctors_import_template.xls
# أو تحديد مسار أي ملف تم تعبئته:
npm run doctors:import -- "C:/path/to/doctors_data.xls"
```

### 3. إعادة توليد النماذج الفارغة في أي وقت:
```bash
npm run doctors:template
```

### 4. مزايا الرفع التلقائي:
- **المطابقة الذكية:** يتعرف السكريبت على اللجان والتخصصات حتى لو كانت هناك اختلافات طفيفة في الهمزات أو الأقواس.
- **منع التكرار والتحديث الذكي:** إذا كان الطبيب مسجلاً مسبقاً بنفس الرقم القومي أو الاسم، يقوم السكريبت بتحديث بياناته بدلاً من تكرار قيده.
- **التشفير الحكومي الأمني:** يتم تشفير الأرقام القومية والحسابات والبطاقات البنكية فوراً بمفتاح تشفير `AES-256-GCM` قبل تخزينها.
- **تدوين سجل الرقابة والتدقيق (Audit Log):** يتم توثيق عملية الإضافة في سجلات الرقابة الإدارية بالمنظومة.
